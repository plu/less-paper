Servers that would not add, custom fields that went missing, and search in more places.

• Fixed: a server could refuse to be added at all, answering only that the data could not be read. A saved view with no sort field was enough to cause it, and so was a saved view using a filter this app did not recognise.
• Fixed: one custom field with an unusual select option made every custom field disappear.
• Saved views using the simple title search and simple text search filters now work.
• Search the lists in Settings: correspondents, custom fields, document types, PDF passwords, saved views, storage paths, tags and trash.
• Diagnostics is now reachable before a server has been added, so a problem on the very first screen can still be reported.

If you hit a problem, please open an issue at https://github.com/plu/less-paper/issues — it is the quickest way to get it fixed.
