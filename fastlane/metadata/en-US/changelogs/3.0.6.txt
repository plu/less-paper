Small fixes to the File Tasks list that arrived with the last release.

• A completed import's row is now tappable across its whole width, so the document it created opens on the first try instead of only when you hit the text.
• A document opened from File Tasks now keeps its title in the compact bar, the way it looks everywhere else in the app.

If you hit a problem, please open an issue at https://github.com/plu/less-paper/issues — it is the quickest way to get it fixed.
